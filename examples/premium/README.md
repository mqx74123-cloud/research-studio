# 合成高级图谱测试集

本目录包含冻结的合成测试输入，不对应真实商家、行政区或城市街网。它最初以固定随机种子 20261005 构建，用于版式、审计与 KDE 验证。

- `synthetic_poi_raw.csv`：3,640 行；审计保留 3,440 行
- `synthetic_boundary.geojson`：虚构研究区边界，声明为 WGS84 经纬度
- `generated_context_utm.geojson`：虚构道路、建筑、绿地、水系及边界背景，EPSG:32650 米制坐标；每个要素具有合成标识
- 三个 `demo*.json` 使用同一数据和密度参数，仅图面主题不同

这些输入作为稳定回归 fixture 随包保存。CLI 重跑会重现记录判断、表格与密度数值；PNG/PDF/SVG 字节可能因软件和字体版本不同而变化。日期是合成来源字段，不代表开业、采集或真实经营变化。

真实输入不可沿用这些背景，也不可漏改 `synthetic` 标志、坐标约定或字段映射。没有背景文件时删除 `context`。
