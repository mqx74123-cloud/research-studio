# 使用说明

## 第一次出图

1. 启动后先打开 Excel / CSV 表格，再进入第二步“选择图形”，选取需要的图形。新模板页面也提供“载入合成示例”和中文 Excel 模板。
2. 选择工作表、表头行，点击“读取所选表格”。核对前五行。
3. 选择图形和对应列，说明每行代表什么，勾选已核对。
4. 设置标题、尺寸和 DPI，生成后下载 PNG / SVG / PDF 或全部结果 ZIP。
5. 如需以后继续调整，展开“我的方案与历史结果”，命名并保存。恢复后重新核对字段再生成。

模板文件：`examples/templates/research.xlsx`。所有随包示例均为虚构数据，不代表研究结论。

## 数据与统计口径

- 热图不自动聚合重复标签。原值模式共用色标，适用于同尺度指标；异量纲指标可选列内中秩百分位，文字仍显示原值。全空行仍保留为 NA，只要表中有其他有效数值。
- 相关矩阵采用逐对完整样本 Pearson r；`correlation_pairs.csv` 写出各对样本数。常量或少于两对为 NA，不自动做显著性检验。
- 森林图仅绘制输入的估计值和区间，要求“下限 ≤ 估计值 ≤ 上限”；需要填写真实的区间定义，不补造置信区间。
- 雨云图按每个指标分别处理缺失值，显示全部有效原始点、IQR、中位数、最小 / 最大值。密度采用 Scott 带宽，各组等峰宽；少于三个观测或常量时不画密度。每组标 n，汇总见 `distribution_summary.csv`。超过 5,000 个点时只栅格化散点层，数据不抽样。
- 列表最多 120 行，每页 30 行；相关矩阵支持更多观测，最多 12 个指标。雨云最多 12 组、12 个指标，每页 4 项。极长标签或过小画布仍需在 SVG 中调整，正式使用前检查实际输出。

## 保存位置和迁移

软件目录下 `gui-work/projects` 保存方案与输入快照，`gui-work/jobs` 保存历史任务、报告、配置、输入、图件和结果 ZIP。复制整个软件文件夹即可连同方案迁移；仅复制启动脚本不能运行。中断的任务重新启动后标记为未完成，需要重新生成。

历史结果保留本次输出，方案用于再次修改设置并出图。软件不会自动清理历史；不再需要的任务可在关闭服务后自行整理。分享结果 ZIP 或软件工作目录时，里面可能含你导入的原始数据。

SVG“可编辑文字”依赖接收方安装对应字体；“文字转轮廓”便于保持外观。PDF 内嵌字体。源码仓库不分发 Windows 商业字体，默认使用电脑现有中文字体；字体警告可在运行记录中查看。
