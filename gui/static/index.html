方法：取所选经度 / 纬度列全部坐标的最小值和最大值，构造轴对齐矩形；每侧增加对应轴跨度的上述比例，且至少留白 0.001°。这是角度留白，不是等距离米制缓冲。缺失、非有限或越界坐标会停止生成，不能根据此矩形报告行政区内外数量或正式研究区面积；核密度边缘也受它影响。实际范围和留白写入导入报告

三步，从 Excel 到图件
  1. 打开表格，检查有没有读对
    支持 .xlsx、CSV 和分隔文本。Excel 有多张工作表时选一张；列名不在第一行时修改表头行号。表头要不重复，数据里不要夹着合并单元格、大标题或小计行。中文列名可以直接用
  2. 选择你想看的内容
    地图看位置；散点图看两个指标的关系；半小提琴比较不同组的一项数值；四象限按两个指标的高低分组。切换图形不会丢掉自己的表格
  3. 选择对应列，检查后生成
    下拉框会显示列名和示例值。软件不会悄悄替你选择数值列，列名建议需要你点选并确认。地图需要明确的坐标系。默认使用真实的 GeoJSON 研究区轮廓；暂时没有轮廓时，可以明确选择只做点位范围预览（非行政区 / 正式研究区边界）
地图的经纬度不等于一定是 WGS84。GCJ-02 / BD-09 需要先转换并记录方法。统计图使用你已有的指标，不会自动把 POI 数量解释成研究结论
结果可以下载 PNG / SVG / PDF，或全部结果 ZIP。ZIP 包括原始输入、配置、审计或排除台账与哈希清单，分享前请检查隐私
本地版已附带 Python 和依赖。解压后双击“启动制图界面-Windows.bat”，无需联网安装。不需要付费 API 或 Codex。Excel 模板为虚构示例，真实分析请替换数据
关闭启动命令窗口会结束服务。历史结果留在 gui-work/jobs 文件夹，可以从“我的方案与历史结果”重新打开。此版本是本机制图工具，不含在线底图、地理编码或坐标偏移转换
